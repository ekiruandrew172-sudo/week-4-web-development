# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application designed to help users track their income and expenses in one place. The project provides a clean and organized interface for recording expenses and viewing recent spending.

## Features

* Displays total income.
* Displays total expenses.
* Displays the remaining balance.
* Add Expense form.
* Expense name input.
* Amount input.
* Expense category selection.
* Expense table with:

  * Name
  * Amount
  * Category
  * Date
* Responsive and user-friendly layout.
* Clean typography and consistent color styling.

## Expense Categories

The tracker includes the following categories:

* Food
* Transport
* Rent
* Entertainment
* Other

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click inside the file and select **Open with Live Server**, if Live Server is installed.
5. Alternatively, double-click `index.html` to open it directly in a web browser.
